# موقع عمرة التيسير

موقع تعريفي بباقات اشتراك "عمرة التيسير"، مع نموذج تسجيل يحفظ بيانات المشتركين مباشرة في **Google Sheet**.

## 📁 محتويات المشروع

```
index.html              الصفحة كاملة (تصميم + شعار وصور + نموذج) — ملف واحد فقط
google-apps-script.gs     كود الخادم (يُنسخ داخل Google Apps Script)
```

`index.html` ملف واحد مستقل بالكامل: التنسيقات والشعار والصور كلها مدمجة بداخله (بصيغة base64)، فمش محتاج ترفع أي مجلد صور منفصل ولا ملفات CSS/JS إضافية.

## 🚀 الخطوة ١: رفع الموقع على GitHub Pages

1. أنشئ مستودع (Repository) جديد على GitHub، مثلاً باسم `omra-taisir`.
2. ارفع ملف `index.html` فقط (وملف `google-apps-script.gs` إذا حبيت تحتفظ بنسخة منه في المستودع) إلى المستودع.
3. من إعدادات المستودع Settings → Pages:
   - اختر Source: **Deploy from a branch**
   - اختر الفرع `main` والمجلد `/ (root)`
   - احفظ، وسيظهر لك رابط الموقع بعد دقيقة أو اثنتين، بالشكل:
     `https://<اسم-المستخدم>.github.io/omra-taisir/`

## 📊 الخطوة ٢: ربط النموذج بجوجل شيت

1. افتح [Google Sheets](https://sheets.google.com) وأنشئ ملف (Sheet) جديد فارغ، وسمّه مثلاً "تسجيلات عمرة التيسير".
2. من القائمة العلوية: **Extensions (الإضافات) → Apps Script**.
3. سيفتح محرر أكواد، امسح أي كود موجود بداخله، وانسخ محتوى ملف `google-apps-script.gs` المرفق هنا والصقه بالكامل.
4. احفظ المشروع (أيقونة الحفظ، أو Ctrl+S) وسمّه مثلاً "Omra Taisir Form".
5. اضغط على زر **Deploy (نشر) → New deployment (نشر جديد)**.
   - اختر النوع (Select type): **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اضغط **Deploy**.
6. أول مرة سيطلب منك Google صلاحيات الموافقة (Authorize access) — وافق باستخدام حسابك.
7. بعد النشر، سيظهر لك رابط بالشكل:
   `https://script.google.com/macros/s/XXXXXXXXXXXXXXXX/exec`
   انسخ هذا الرابط.

## 🔗 الخطوة ٣: إضافة الرابط للموقع

1. افتح ملف `index.html` وابحث (Ctrl+F) عن السطر:
   ```js
   const SHEET_WEBAPP_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_URL_HERE";
   ```
2. استبدل القيمة بالرابط الذي نسخته في الخطوة السابقة، ليصبح مثلاً:
   ```js
   const SHEET_WEBAPP_URL = "https://script.google.com/macros/s/XXXXXXXXXXXXXXXX/exec";
   ```
3. احفظ الملف وارفعه مرة أخرى (Push/Commit) إلى GitHub — سيتحدث الموقع تلقائيًا خلال دقيقة.

الآن، أي شخص يملأ النموذج في قسم "سجّل الآن" ستُضاف بياناته كصف جديد تلقائيًا في نفس الـ Google Sheet (الاسم، رقم الهاتف، الباقة، الملاحظات، وتاريخ التسجيل).

## ✏️ تعديلات سريعة عليك القيام بها

- **رقم الهاتف/واتساب**: في `index.html` ابحث عن `tel:+20000000000` و `wa.me/20000000000` (في أعلى الصفحة وفي الفوتر) واستبدلهما برقمك الحقيقي.
- **الألوان**: ابحث داخل `index.html` عن `:root {` (بداية قسم `<style>`) وعدّل درجات الذهبي والألوان من هناك.
- **الشعار والصور**: مدمجة داخل الملف كـ base64، فلو حبيت تستبدلها لاحقًا يفضّل ترجع لنسخة تستخدم مجلد `assets/` منفصل بدل تعديل النص المشفّر مباشرة.

## ⚠️ ملاحظة أمنية

لأن الموقع ثابت (Static) ولا يحتوي على خادم خاص بك، رابط Apps Script سيكون ظاهرًا لمن يفحص كود الصفحة. هذا وضع طبيعي وآمن طالما أن الصلاحية "Execute as: Me" مفعّلة — أي أن الكتابة في الشيت تتم دائمًا من خلال حسابك أنت وليس بصلاحيات الزائر، وأقصى ما يمكن لأي شخص فعله هو إرسال بيانات وهمية للنموذج نفسه (مثل أي نموذج تواصل عام على الإنترنت).
